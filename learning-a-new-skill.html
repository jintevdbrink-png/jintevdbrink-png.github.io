9 Learning a new skill

The skill that is learned is ‘Learning to apply machine learning techniques to predict whether a person has cancer or not’.

Machine learning is becoming important in bioinformatics and medical data analysis. In biomedical research and diagnostics, machine learning models are often used to recognize patterns in large datasets and make predictions about diseases such as cancer.

This skill aligns with future plans within bioinformatics because it combines programming, statistics, and biological data analysis. Learning how to preprocess data, train machine learning models, evaluate model performance, and interpret results is highly relevant for future research projects and internships.

9.2 Step 1 — Orientation

In this step, I started learning the basic concepts of machine learning to better understand how prediction models work.

I learned about machine learning concepts from two YouTube videos [@video1] and [@video2]. These videos helped me understand the main types of machine learning and how they differ from each other.

The first video focused on explaining supervised, unsupervised, and reinforcement learning in a general way. The second video gave practical examples of how machine learning models learn patterns from data and use these patterns to make predictions.

9.2.1 Key concepts learned:

Supervised learning
Supervised learning is a type of machine learning where the model is trained using labeled data. This means that both the input data and the correct output are known. In this project, cancer prediction is an example of supervised learning because the model learns from labeled medical data (cancer vs. no cancer).

Unsupervised learning
Unsupervised learning is when the model works with data that has no labels. The goal is to find patterns or structures in the data without predefined answers.

Reinforcement learning
Reinforcement learning is a method where an agent learns by interacting with an environment and receiving rewards or penalties based on its actions.

9.2.2 Conclusion

After watching both videos, I now understand the basic differences between the main types of machine learning and how supervised learning is especially relevant for cancer prediction tasks.

9.2.6 Splitting the data

inTraining <- createDataPartition(data$Species, p = .75, list = FALSE)
training <- data[ inTraining,]
testing  <- data[-inTraining,]

9.5 Step 4 — Data preprocessing

This step is used to make the data tidy, so it can be used for the training.

9.5.1 Removing the Id column

The Id column is removed because it does not contain useful biological information for the model.

data$Id <- NULL

9.5.2 Replacing missing values

In this dataset, missing values are represented as “?”. These are converted to NA values. After that the rows containing NA are removed from the dataset.

data[data == "?"] <- NA
data <- na.omit(data)

9.5.3 Converting variables to numeric

One challenge during preprocessing was that several variables were stored as factors instead of numeric values. This caused problems for machine learning models and therefore needed to be corrected.

data[ ,1:9] <- lapply(data[ ,1:9], function(x) as.numeric(as.character(x)))
