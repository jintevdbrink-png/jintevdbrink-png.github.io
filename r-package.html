6 R package

The package contains functions for cleaning datasets, such as removing duplicate rows, handling missing values, and removing empty columns.

In addition, the package includes a data quality report function that provides an overview of missing values and duplicate rows in a dataset.

The package is available on GitHub and can be installed using devtools::install_github(“jintevdbrink-png/datacleaner”).
